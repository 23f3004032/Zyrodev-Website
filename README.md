# Zyrodev

My personal software brand and portfolio site — where I show off the mobile, web, and AI/ML work I build for clients, plus a few internal products I'm developing on the side.

**Live:** [zyrodev.com](https://zyrodev.com/)

## Sections

- **Hero** — landing intro with the Zyrodev name and tagline
- **Stats** — a scrolling strip of numbers/highlights
- **Mobile App Development** — showcase of shipped mobile apps (Flutter, React Native, native Android/iOS), each with a demo video, tech stack, and a short case-study blurb
- **Web Development** — same treatment for web projects, from e-commerce storefronts to SaaS dashboards
- **AI/ML Solutions** — machine learning and automation work: analytics dashboards, RAG/semantic search, OCR pipelines, conversational agents
- **Our Products** — internal product concepts (facility management, legal analytics, hospital information system, prescription OCR)
- **Portfolio modal** — a filterable gallery pulling from all the project categories above
- **About modal** — the team behind Zyrodev
- **Contact modal** — a working contact form that emails submissions via Gmail SMTP
- **Book a Meeting modal** — a call-booking form
- **Footer** — quick links, services summary, and direct email contact

## Tech stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion and GSAP for animation
- Three.js with React Three Fiber/Drei/Postprocessing for the 3D visuals
- Lenis for smooth scrolling
- Nodemailer for the contact and booking form emails (Next.js API routes)
- Deployed on Netlify
